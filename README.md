# Spark

Концепт сайта студии пилатеса, растяжки и йоги для портфолио. Студия, тренеры и контакты вымышлены.

- первый экран с анимированными облаками, солнцем и искрами
- бенто «Почему к нам возвращаются», четыре направления
- интерактивное расписание на неделю с фильтрами и записью на занятие
- абонементы, тренеры, фото студии, частые вопросы
- форма записи на пробное занятие с согласием на обработку данных

Статический сайт: HTML, CSS, JavaScript без сборки. Фото — Pexels и Unsplash, шрифт Geologica хранится на сайте.
